# Guía rápida · Borealis Repuestos

_Romero Alfa 1 · Tenga esta hoja junto a la computadora_

## 1. Vender

1. En la pantalla principal pulse **[F5]** (Vender).
2. Escanee el código de barras: el producto se agrega solo.
3. O escriba palabras del nombre (ej. «pastilla bera») y **[Enter]**; elija con **[↑]** **[↓]** y **[Enter]**.
4. Escriba la cantidad y **[Enter]**. Para metros o litros use coma: 2,5.
5. **[F4]** cambia la cantidad del renglón elegido · **[Supr]** lo quita · **[F3]** elige el cliente.
6. **[Esc]** cancela la venta.

## 2. Cobrar y dar vuelto

1. Pulse **[F9]**. Elija la forma de pago: **[F1]** efectivo Bs · **[F2]** efectivo USD · **[F3]** punto · **[F4]** pago móvil.
2. Escriba el monto y **[Enter]**. Con el monto vacío, **[Enter]** completa lo que falta.
3. Si hay vuelto: escriba cuántos USD entrega (puede ser 0); el sistema dice el resto en Bs.
4. Pulse **[F9]** para cobrar: sale la nota de entrega. Si la impresora falla, la venta queda guardada.
5. Fiado: con un cliente que tenga fiado, **[F6]** manda a fiado lo que falta.

## 3. Abrir y cerrar la caja

1. Abrir: Caja → escriba el efectivo que hay en USD y en Bs → Abrir caja. Sin caja abierta no se vende.
2. Salida de efectivo (pagos, gastos): Caja → Salida de efectivo, monto y motivo → Registrar.
3. Cerrar: cuente el efectivo → Cerrar caja… → escriba lo contado en USD y Bs.
4. Sale el ticket de cierre y se hace un respaldo. Solo la dueña ve lo esperado y la diferencia.

## 4. Registrar una compra (dueña)

1. Compras → **[Ctrl+N]**. Elija el proveedor (o «Nuevo proveedor…»), la factura y la fecha.
2. Producto **[Enter]** → cantidad **[Enter]** → costo unitario USD **[Enter]** para agregar el renglón.
3. Si viene por caja o docena: **[F4]** «Por empaque» calcula unidades y costo.
4. **[Ctrl+S]** guarda: suben las existencias y se actualiza el costo promedio.

## 5. Ver qué pedir (dueña)

1. La pantalla principal avisa «Para pedir: N productos» → Ver la lista.
2. O Inventario → Para pedir: por categoría, con el último proveedor y costo.
3. Para imprimirla: Reportes → Para pedir → Ver → Imprimir.

## 6. Registrar un abono de fiado

1. Fiado → Deudores → elija el cliente → Registrar abono (la caja debe estar abierta).
2. Elija la forma de pago y el monto: el sistema muestra cuánto abona en USD y cómo queda el saldo.
3. Guardar abono: sale el comprobante AB-…; se aplica a la deuda más vieja primero.

## Bueno saber

- La tasa BCV se descarga sola. Si dice «sin tasa»: Tasa BCV → Cargar a mano.
- El respaldo es automático (al abrir, al cerrar caja y al salir) y se copia a Google Drive.
- ¿Dudas? Escriba a Borealis por WhatsApp. Nunca borre la carpeta C:\ProgramData\BorealisRepuestos.
